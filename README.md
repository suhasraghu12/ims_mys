# Shop Khata

A credit book PWA for the shop. Photograph the handwritten bill, pick the customer, type the total,
and send the photo + balance to the customer on WhatsApp.

## V1 features

- **New bill in 3 taps**: camera opens straight away → pick customer (recent first) → type total → send.
- **10-second undo** before anything is saved.
- **WhatsApp**: bill photo + message (+ your UPI QR photo) via the phone's share sheet.
- **Payments**: cash / UPI / other, "Full amount" shortcut, optional receipt photo, receipt message.
- **Credit warning** when a customer is over their credit limit or overdue too long.
- **Payment cycle per customer**: weekly, 15 days, monthly, or a fixed date each month (salary day).
- **Reminders list**: overdue and due-soon customers first; resends unpaid bill photos.
- **Duplicate warning**: same photo saved twice, or same amount for the same customer on the same day.
- **PIN lock** (locks again after 5 minutes away), **offline**, **backup / restore** (Google Drive or WhatsApp).
- Message text is editable in Settings, so it can be written in any language.

## Run on a computer

Built with **React + Vite**. Needs Node.js 20+.

```sh
npm install
npm run dev       # live-reloading dev server → http://localhost:5173
npm run build     # production build into dist/
npm run preview   # serve the built dist/ locally
```

## Put it on the phone

Camera, sharing and install only work over **HTTPS**. Run `npm run build`, then host the **`dist/`** folder
on any free static host:

- **Netlify Drop**: drag the `dist` folder onto https://app.netlify.com/drop
- or GitHub Pages / Cloudflare Pages (build command `npm run build`, output folder `dist`)

Open the link in **Chrome on Android** → menu → **Add to Home screen / Install app**.

The offline service worker is generated by the build, and installed phones update themselves on the next launch.
Keep the same web address as before so existing data on the phone carries over.

## Cloud sync (MongoDB)

Phones keep working offline; the small server in `server/` syncs them through MongoDB Atlas and keeps a
cloud copy (customers, bills, payments, shared settings). Bill photos are stored **privately in Cloudinary**
(viewable only through signed links the server makes; thumbnails are generated by Cloudinary). The database
password and Cloudinary secret live **only** in the server's `.env` — never in the app.

1. Copy `.env.example` to `.env` and fill in `MONGO_URI`, `MONGO_DB_NAME`, `CLOUDINARY_URL` and a long random `SHOP_KEY`.
2. `npm run build` then `npm start` → app + API on http://localhost:8787.
   While developing, run `npm run server` and `npm run dev` side by side (Vite forwards `/api` to the server).
3. On each phone: **Settings → Cloud sync** → enter the shop key (and the server address if the app is hosted
   somewhere else) → **Connect & sync**. A new phone can use **Connect to cloud** on the welcome screen.

Sync runs on open, a few seconds after every save, every 2 minutes, and when the internet comes back.
If two phones change the same record, the most recent change wins. PIN and backup date stay per phone.

**Hosting** (e.g. Render / Railway web service): build command `npm install && npm run build`, start command
`npm start`, and add `MONGO_URI`, `MONGO_DB_NAME`, `SHOP_KEY`, `CLOUDINARY_URL` as environment variables. In Atlas → Network
Access, allow the host's outgoing IPs. To cut off a lost phone, change `SHOP_KEY` and reconnect the others.

## Things to know

- Without cloud sync, data is stored **only on that phone**. Take a backup every week; the home screen warns
  if you haven't (not needed while cloud sync is working). Clearing Chrome's site data deletes the phone's copy.
- WhatsApp opens with the photo and message ready; you choose the contact and press Send.
  Fully automatic sending needs the paid WhatsApp Business API.
- A forgotten PIN can't be recovered. The only way back in is to restore a backup on a fresh install.

## Files

| File | What it does |
|---|---|
| `src/App.jsx` | Lock / setup gate, screen switching, re-lock after 5 minutes |
| `src/screens/` | Home, bill & payment entry, customers, customer page, reminders, settings |
| `src/actions.jsx` | Flows: save bill/payment with 10-second undo, WhatsApp sharing, customer form, PIN, backup |
| `src/ui/` | Shared components (icons, keypad, ring chart, status pill), bottom tab bar, sheets, toast, router |
| `src/lib/store.js` | App state (React `useSyncExternalStore`) on top of IndexedDB |
| `src/lib/logic.js` | Balances, due dates, credit warnings, message templates |
| `src/lib/db.js` | On-phone storage (IndexedDB) |
| `src/lib/image.js` | Photo shrinking and hashing |
| `src/styles.css` | Design tokens and styles (light + dark) |
| `vite.config.js` | Build + PWA manifest and offline service worker |
| `src/lib/sync.js` | Cloud sync: push/pull, photo upload/download, auto-sync |
| `server/index.js` | Sync API on MongoDB + private photo storage on Cloudinary (Express); serves the built app |
